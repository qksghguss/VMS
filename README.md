# 작업일보 실적집계 GUI 프로그램 (INI 설정 + 프로그램 내 설정/실행)

## 특징
- 설정을 엑셀로 저장하지 않고 `config.ini`로 저장
- 프로그램 내부 화면에서:
  - 원본 파일 경로/시트/헤더행 설정
  - 열 매핑(헤더명 또는 A,B,C 컬럼문자)
  - 제외자 관리
  - 기간(시작/종료) 설정
  - 랭킹 기준/반올림/결과 파일명 설정
  - 집계 실행 + 대시보드(표/그래프)
  - 엑셀 결과 내보내기

## 설치/실행
```bash
pip install -r requirements.txt
python app.py
```

## config.ini 위치
- `app.py` 실행 폴더에 `config.ini`가 있어야 합니다.
- 프로그램에서 '설정 저장' 버튼을 누르면 현재 폴더의 config.ini가 갱신됩니다.

## 결과 엑셀
- '결과 엑셀로 내보내기' 버튼으로 저장 위치를 선택해서 저장합니다.
- 시트: 일일집계, 최종집계_요약, 최종집계_상세


## 이번 개선 사항 (UI/UX + 기능)
- **1920x1080 전체화면 기준 가독성 개선**
  - 탭/버튼/입력창 기본 높이와 패딩을 조정해 조작 피로도를 낮춤
  - 대시보드 요약 카드(총 작업자 / TOP 작업자 / 총 매수) 추가
- **소스 파일 선택 UX 개선**
  - 설정 탭에서 선택한 소스 행에 대해 파일 탐색기로 경로를 바로 입력 가능
- **입력 검증 강화**
  - 헤더행 1 미만 입력 차단
  - 사용 소스가 0개인 경우 집계 실행 차단
- **집계 규칙 개선 (granularity 실제 반영)**
  - `daily/weekly/monthly` 선택값을 기간 라벨로 반영해 일일집계 시트와 차트 집계 단위가 일치
  - 주간은 ISO week(`YYYY-Www`), 월간은 `YYYY-MM` 형식 사용
- **대시보드 시각 개선**
  - 요약 표 줄무늬 적용
  - 기간별 추이 그래프에 마커 추가 및 제목에 집계 단위 표시
