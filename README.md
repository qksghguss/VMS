# 작업일보 실적집계 GUI 프로그램 (INI 설정 + 프로그램 내 설정/실행)

## 특징
- 설정을 엑셀로 저장하지 않고 `config.ini`로 저장
- 프로그램 내부 화면에서:
  - 원본 파일 경로/시트/헤더행 설정
  - 열 매핑(헤더명 또는 A,B,C 컬럼문자)
  - 제외자 관리
  - 기간(시작/종료) 설정
  - 랭킹 기준/반올림/결과 파일명 설정
  - 집계 실행 + 대시보드(표/그래프)
  - 엑셀 결과 내보내기

## 설치/실행
```bash
pip install -r requirements.txt
python app.py
```

## config.ini 위치
- `app.py` 실행 폴더에 `config.ini`가 있어야 합니다.
- 프로그램에서 '설정 저장' 버튼을 누르면 현재 폴더의 config.ini가 갱신됩니다.

## 결과 엑셀
- '결과 엑셀로 내보내기' 버튼으로 저장 위치를 선택해서 저장합니다.
- 시트: 일일집계, 최종집계_요약, 최종집계_상세
