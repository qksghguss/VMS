# 작업일보 실적집계 GUI 프로그램 (INI 설정 + 프로그램 내 설정/실행)

## 특징
- 설정을 엑셀로 저장하지 않고 `config.ini`로 저장
- 프로그램 내부 화면에서:
  - 원본 파일 경로/시트/헤더행 설정
  - 열 매핑(헤더명 또는 A,B,C 컬럼문자)
  - 제외자 관리
  - 기간(시작/종료) 설정
  - 랭킹 기준/반올림/결과 파일명 설정
  - 집계 실행 + 대시보드(표/그래프)
  - 엑셀 결과 내보내기

## 설치/실행
```bash
pip install -r requirements.txt
python app.py
```

## config.ini 위치
- `app.py` 실행 폴더에 `config.ini`가 있어야 합니다.
- 프로그램 시작 시 자동으로 불러오며, 집계 실행/종료 시 자동 저장됩니다.
- 필요 시 `설정 저장` 버튼으로 즉시 저장할 수 있습니다.

## 결과 엑셀
- `결과 엑셀로 내보내기` 버튼으로 저장 위치를 선택해서 저장합니다.
- 시트
  - `일일집계`: 기간(일/주/월) x 작업자 집계
  - `최종집계_요약`: 작업자 x 작업일보 집계 (랭킹)
  - `최종집계_상세`: 기간 x 작업자 x 작업일보 상세 집계

## 주요 개선 포인트
- 소스 테이블 컬럼 폭 재조정 + 파일경로 전용 `...` 버튼(행별)
- 파일 선택 시 해당 엑셀의 시트 목록을 자동 로드하여 콤보박스 선택
- 기간 필터 체크박스를 1개로 단순화
- 기간/출력/랭킹 영역에 닫기/종료 버튼 추가
- 열 매핑 테이블은 스크롤 없이 전 항목 표시되도록 고정 높이 처리
- 대시보드 표/차트에서 한글 폰트 깨짐 완화(가능한 시스템 한글 폰트 자동 선택)
